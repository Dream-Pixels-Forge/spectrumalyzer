Quick start

One install gets everything — DSP engine plus semantic hearing.

brew install ffmpeg   # or: apt install / winget install ffmpeg
pip install spectrumalyzer
macOS · Debian/Ubuntu · Windows. Embedding weights (~90 MB) auto-download on first use.
1

Analyze a track for a 30 fps project, in three formats at once:

spectrumalyzer analyze song.mp3 --fps 30 --format remotion,csv,ae
2

Open a self-contained visual report in your browser:

spectrumalyzer report song.mp3 -o song.html
3

Need a 90 s bed for video instead of the full song?

spectrumalyzer trim song.mp3 --length 90 -o bed.mp3

How it works

One pipeline: decode → analyze → frame-ize → export. Each stage is an independent, testable component.

Decode

ffmpeg turns any audio — or a video's audio track — into clean mono PCM. If ffmpeg plays it, spectrumalyzer reads it.

Analyze

STFT + spectral flux find onsets; autocorrelation finds the tempo; the beat grid phase-locks to the kick; 6 frequency bands and song sections fill in the picture.

Frame-ize

Every timestamp and band row is converted to your project's fps at --fps — copy-paste numbers straight into keyframes.

Export

Pure, tested renderers emit each tool's dialect from the same analysis — no drift between formats.

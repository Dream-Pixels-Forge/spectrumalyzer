MCP & agents

spectrumalyzer as native tools for AI agents — a blocking stdio MCP server plus an installable agent skill. Everything stays local.

Run the server

spectrumalyzer mcp    # blocking stdio MCP server

The server exposes analysis, semantic hearing, export and trim as native MCP tools over stdin/stdout. It's blocking by design — launch it as a long-lived process from the client's MCP config, exactly like any stdio server.

Register with your client

Claude Desktop (or any JSON-config MCP host)

{
  "mcpServers": {
    "spectrumalyzer": { "command": "spectrumalyzer", "args": ["mcp"] }
  }
}

pi / pi-coding-agent

Add to ~/.pi/agent/mcp.json:

{"mcpServers": {"spectrumalyzer": {"command": "spectrumalyzer", "args": ["mcp"]}}}

Once registered, the agent gets the tools below natively — ask it to "analyze this track and export Remotion beats" and it runs the full pipeline without shell access.

Tool table

ToolWhat the agent gets
analyze_audioBPM, beat grid, onsets, sections (lean JSON; pass include_analysis for the full band matrices)
describe_audioNatural-language description + mood/energy/flavor/use tags
find_musicSemantic search over a library ("calm warm bed for an intro")
export_beatsWrites Remotion / HyperFrames / AE / FCPXML / CSV deliverables
render_reportSelf-contained HTML visual report
model_statusEmbedding model state (diagnostics)
trim_audioBest short version of a long track/video for video use (window + ffmpeg cut)
Failure behavior

Tools are read-only with respect to your audio; the only writes are the explicit deliverable paths you pass (export_beats, render_report, trim_audio). Errors come back as structured {"error": ...} payloads instead of crashes, so agents can react gracefully.

Agent skill — teach your agent to use it

Install the spectrumalyzer skill into any skill-aware agent (pi, Claude Code, OpenCode, …):

npx skills add Dream-Pixels-Forge/spectrumalyzer/skills/spectrumalyzer
Path format

The skills CLI takes owner/repo/subpath — GitHub's tree/<branch>/ URL syntax is not supported (it would be treated as a literal folder name).

The skill lives in this repo at skills/spectrumalyzer/SKILL.md and covers when and how to use spectrumalyzer: analysis for scene timing, semantic music search, the signal→animation mapping (bass → glow, treble → sparkle), MCP tool selection, and export-format choice per creative tool. Useful even before the MCP server is registered — and complementary to it.

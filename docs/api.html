Python API

One import does everything. The public surface is deliberately small: two functions and typed dataclasses.

from spectrumalyzer import analyze, trim
from spectrumalyzer import AnalysisResult, Beat, Section, TrimSelection, __version__

analyze() — the whole engine in one call

def analyze(
    path: str,
    fps: float | None = None,
    bands: bool = True,
    sections: bool = True,
    min_bpm: float = 60.0,
    max_bpm: float = 200.0,
    sample_rate: int = 44100,
    waveform_buckets: int = 400,
) -> AnalysisResult
ArgumentDefaultWhat it does
path—Any file ffmpeg reads: mp3, wav, flac, ogg, m4a, or video (audio track extracted automatically).
fpsNoneWhen set, every timestamp gains frame numbers at this rate — creative tools work in frames, not seconds.
bandsTrueInclude per-frame frequency-band energies (6 bands).
sectionsTrueAttempt song-structure segmentation (quiet / mid / high / peak).
min_bpm / max_bpm60 / 200Tempo search window hints.
sample_rate44100Internal decode rate.
waveform_buckets400Resolution of the visualization waveform.

Raises ValueError when the file contains no decodable audio. Every CLI flag has a keyword-argument twin (--no-bands → bands=False).

trim() — best short version of a long track

def trim(
    path: str,
    target_seconds: float = 90.0,
    output: str | None = None,
    crossfade: float = 0.5,
) -> tuple[TrimSelection, str | None]

Analyzes path, picks the best window (loudness + onset density + section energy, cuts snapped to the beat grid), and cuts it with ffmpeg. Returns (selection, written_path) — written_path is None when the track was already short enough (nothing cut).

Lower-level pieces, useful when you want the decision without the cut:

from spectrumalyzer import analyze, select_trim_window, trim_audio

result = analyze("song.mp3")
sel = select_trim_window(result, 90, snap_to_beats=True)  # -> TrimSelection
if sel.trimmed:
    trim_audio("song.mp3", "bed.mp3", sel.start, sel.end, crossfade=0.5)
No-op guarantee

If the track is already ≤ the target length, TrimSelection.trimmed is False and the whole track is returned with a reason — no file is written, no fake "trim" reported.

The data model

AnalysisResult is the typed contract everything builds on:

result = analyze("song.mp3", fps=30)

result.bpm                    # 128.32
result.bpm_confidence         # 0.91 — 0..1, how strong the tempo pulse is
result.duration               # seconds
result.beats_as_frames()     # [15, 53, 91, ...]  at 30 fps
result.band_rows_at_fps()    # one [sub, bass, lowMid, mid, highMid, treble] row per video frame
result.sections               # [Section(start, end, energy, label), ...]
result.centroid               # spectral brightness per frame
result.loudness               # relative loudness envelope
result.loudness_db           # absolute RMS loudness in dBFS
result.to_dict()              # JSON-ready dict (what the JSON export writes)
result.to_legacy_dict()      # old bpm/beats/beatTimes contract for v0.1 consumers
TypeFields / methods
Beattime, frame (when fps set), strength; to_dict(fps)
Sectionstart, end, energy, label (quiet/mid/high/peak); duration property
BandDatanames, frame_duration, matrix; row_at(t), resample_to_fps(fps, duration)
TrimSelectionstart, end, reasons; duration, trimmed properties, to_dict()

The frame math is unit-tested: time_to_frame(t, fps) and band resampling align 1:1 with video frames (useCurrentFrame() in Remotion, hf-seek in HyperFrames).

Examples

30 fps beat data for a Remotion composition

from spectrumalyzer import analyze

r = analyze("song.mp3", fps=30)
beats  = r.beats_as_frames()   # keyframe-ready frame numbers
bands  = r.band_rows_at_fps()  # index 1:1 with useCurrentFrame()
print(r.bpm, r.bpm_confidence, len(r.sections))

Programmatic export without the CLI

import json
from spectrumalyzer import analyze
from spectrumalyzer.exporters import export, export_filename

r = analyze("song.mp3", fps=24)
for fmt in ("json", "remotion", "ae"):
    path = export_filename(r, fmt, base="deliverables/song")
    with open(path, "w", encoding="utf-8") as fh:
        fh.write(export(r, fmt))

Attach semantics to an analysis (embeddings)

from spectrumalyzer import analyze
from spectrumalyzer.embedding.describe import describe
from spectrumalyzer.embedding.mood import tag_track

r = analyze("song.mp3")
d = describe(r)              # {"summary": ..., "description": ...}
tags = tag_track(backend, d["text"])  # mood / energy / flavor / use axes

The same logic the --embed flag uses — see Semantic hearing.

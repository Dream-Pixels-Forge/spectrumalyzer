Semantic hearing

Numbers get measured; this layer gives them language. Describe a track in words, tag it by mood, and search your library by meaning — all local.

describe · find · --embed

# describe a track in words + mood/energy/flavor/use tags
spectrumalyzer describe song.mp3 [--top 3]

# semantic search across a library (recursive, cached index)
spectrumalyzer find "calm warm bed for a documentary intro" ./my-library [--limit 10] [--refresh]

# attach description + tags to any analysis JSON
spectrumalyzer analyze song.mp3 --embed -o enriched.json

describe summarizes the track from its measurements (tempo class, loudness, brightness, dominant band, transient density, section contrast), then the embedding model turns that summary into plain language plus a short tag list. find embeds your query and the library, ranks by meaning, and caches the index so repeat searches are instant — --refresh forces re-embedding.

The model

RoleModel
Preferredgoogle/embeddinggemma-300m — Google's current small Gemma embedding model
Fallbacksentence-transformers/all-MiniLM-L6-v2 — non-gated, works everywhere

The weights (~90 MB, one-time) land in ~/.config/spectrumalyzer/embedding/ (XDG_CONFIG_HOME is respected). The preferred model is tried first; if it's unavailable, the fallback is used automatically, so the feature works even where Gated access is missing.

Model lifecycle

spectrumalyzer model pull     # download weights into the local model home
spectrumalyzer model status   # preferred/fallback model + installed state

describe, find and analyze --embed all auto-pull on first use if the weights are missing. Once installed, every run is fully offline.

Local-first

No audio or text ever leaves your machine. The core DSP analysis never depends on the embedding layer — you can use beats/bands/sections without the model present.

How it stays honest

Tags aren't magic. Each track is first summarized in words derived from real measurements, then tagged by blending embedding similarity with a numeric feature-profile match per descriptor — the embedding pulls toward the meaning, the numbers keep it grounded. Pulseless ambient material is reported as "no clear pulse" (and bpm: 0), never an invented tempo. Known limitation: the tag bank is coarse and search discrimination between sonically similar tracks is modest — see the roadmap calibration backlog.

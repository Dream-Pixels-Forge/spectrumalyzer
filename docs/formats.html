Export formats

One analysis, every dialect. The same measurements render into the exact format your tool expects — no drift between tools.

Note on --fps

Everything except json needs --fps — the frame numbers can't be computed without a frame rate. The json format also gains frame fields when you pass --fps.

Remotion in 30 seconds

spectrumalyzer analyze song.mp3 --fps 30 --format remotion
# → song.remotion.json + song.useBeats.ts — copy both next to your composition
import { useBeatPop } from "./song.useBeats";

export const MyScene = () => {
  const scale = useBeatPop(0.15);   // pops 15% on every beat, springs back
  return <h1 style={{ transform: `scale(${scale})` }}>ON BEAT</h1>;
};

The generated hook also includes useBeatIndex(), useBeatProgress(), useIsOnBeat(window), and the raw BEATS / BPM constants. The bandsByFrame array aligns 1:1 with useCurrentFrame() — each row is the six-band energy [sub, bass, lowMid, mid, highMid, treble] for that exact video frame, so bands[useCurrentFrame()] is your audio-reactive lookup with zero runtime math.

After Effects in 30 seconds

spectrumalyzer analyze song.mp3 --fps 30 --format ae
# → song.markers.jsx — then: File → Scripts → Run Script File…

Every beat, hit and section becomes a named comp marker (beat 1, hit, section: peak), stamped inside a single undo group. Enable Layer → Time → marker snapping and keyframe straight to the music. csv and fcpxml carry the same markers into Premiere, Resolve and Final Cut — run one analysis, deliver to every suite.

Raw JSON anatomy

The json format is the complete analysis — everything the other renderers are built from. Abridged view (with --fps 30):

{
  "bpm": 128.32,
  "bpmConfidence": 0.91,          // 0..1 — how strong the tempo pulse is
  "fps": 30,
  "durationInFrames": 7690,
  "beats": [
    { "time": 0.5012, "frame": 15, "strength": 0.87 }
  ],
  "onsets": [                      // raw transients — hits, not grid beats
    { "time": 0.1203, "frame": 4, "strength": 1.0 }
  ],
  "bands": {
    "names": ["sub", "bass", "lowMid", "mid", "highMid", "treble"],
    "frameDuration": 0.0232,
    "matrix": [[0.0, 0.42, 0.11, 0.05, 0.02, 0.01], "…per analysis frame"]
  },
  "bandsByFrame": "…same 6 values, resampled to one row per VIDEO frame",
  "sections": [
    { "start": 0.0, "end": 24.8, "label": "quiet", "energy": 0.22,
      "startFrame": 0, "endFrame": 744 }
  ]
}
